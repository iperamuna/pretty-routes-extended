# Changelog

All notable changes to `pretty-routes-extended` will be documented in this file.

## 1.1.0 - 2026-07-11

- **Laravel 13 Support**: Updated dependencies to support Laravel 13 framework.
- **Dependency Upgrades**: Upgraded Testbench 11 and Pest 4 for development.

## 1.0.0 - 2024-02-17

- Initial release.
- Premium Livewire-powered route visualization.
- Real-time search and prefix filtering.
- Sticky footer with mirrored horizontal scroll.
- Row highlighting and multi-selection support.
- Fully configurable via `pretty-routes-extended.php`.
- Inspired by `garygreen/pretty-routes`.
